# <h1 align="center">🕹️ Survival Game</h1>

<h2 align="center">🎮 게임 소개</h2>

간단한 **2D 생존 게임**입니다.

플레이어는 방향키를 이용하여 이동하며, 지속적으로 생성되는 적을 피하거나 공격하여 최대한 오래 생존하는 것이 목표입니다.

---

<h2 align="center">✨ 게임 방식</h2>

* 플레이어는 **방향키(↑ ↓ ← →)** 를 이용해 이동합니다.
* 적은 플레이어를 자동으로 추적합니다.
* **Space Bar**를 누르면 주변의 적을 공격할 수 있습니다.
* 공격에는 **쿨타임**이 존재합니다.
* 적과 충돌하면 생명이 1 감소합니다.
* 생명이 모두 소진되면 게임이 종료됩니다.

---

<h2 align="center">🎮 조작법</h2>

|    키    | 기능      |
| :-----: | :------ |
| ↑ ↓ ← → | 플레이어 이동 |
|  Space  | 주변 공격   |

---

<h2 align="center">🛠 사용 기술</h2>

**Python**

* 게임 로직 구현
* 플레이어 및 적 객체 관리
* 충돌 판정
* 공격 및 쿨타임 처리

**Pygame**

* 게임 화면 출력
* 키보드 입력 처리
* 프레임 관리
* 사각형(Sprite) 렌더링

---

<h2 align="center">⚙ 주요 기능</h2>

### 👤 Player

* 방향키 이동
* 공격 범위 생성
* 공격 쿨타임
* 생명(HP) 시스템

### 👾 Enemy

* 랜덤 위치에서 생성
* 플레이어 자동 추적
* 충돌 시 플레이어 HP 감소

### ⚔ Combat

* 공격 범위 안의 적 제거
* 공격 애니메이션 표시
* 공격 쿨타임 적용

### 📈 Difficulty

* 일정 시간마다 적이 계속 생성
* 시간이 지날수록 생존 난이도 증가

---

<h2 align="center">▶ 실행 방법</h2>

1. 프로젝트 폴더로 이동합니다.

2. 필요한 라이브러리를 설치합니다.

```bash
pip install pygame
```

3. 게임을 실행합니다.

```bash
python main.py
```

> 파일명이 다르다면 해당 파일명으로 실행하면 됩니다.
